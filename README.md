# Texture Hub

**Texture Hub** is a Geometry Dash texture pack manager built with Geode.

Discover and manage texture packs, inspect pack information, and explore creator-provided settings in one place.

### Features
- Discover existing Texture Loader packs.
- Scan ZIP archives and pack folders.
- Read existing `pack.json` metadata.
- Support optional Texture Hub creator metadata.
- Display pack information, descriptions, credits, and previews.
- Provide creator-defined settings such as toggles and sliders.

### Compatibility
Texture Hub is designed to work alongside the existing Texture Loader system. It does not replace the texture-loading functionality.

### Mod Information
- **Mod ID:** `monofurballs.texture-hub`
- **Platform:** Geometry Dash
- **Framework:** Geode
